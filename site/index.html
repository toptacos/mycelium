The part that works is the part you don't see.

mycelium is a local-first agent workstation. It scaffolds apps, researches the web, writes content, calls your APIs, and runs multi-step workflows — powered by a 522MB model that lives on your machine. Watch it bloom when it starts.

$curl -fsSL https://mycelium.topta.co/mcy | sh
Read the docs Watch it bloom

Roots, not rentals.

Five capabilities, one small binary-sized dependency set, zero subscriptions. Cloud models are optional adapters — the loop itself never leaves your machine.

scaffold

Apps that pass their own tests

Four templates, from Python CLI to FastAPI service. The scaffold's test suite actually runs.

research

Fetch, ground, answer

Pulls a page, strips it, and answers strictly from it — with the source URL recorded.

content

Drafts that respect caps

Blog, README, newsletter, outline, tutorial, changelog. Word limits are enforced, not suggested.

connect

Your APIs, your tokens

Connection profiles in TOML. Tokens are read from the environment at call time and never logged.

workflows

Steps that resume

YAML workflows with variable passing, dry-run, and checkpoints — pick up where it failed.

remember

It learns as it goes

Every run is distilled into memory and recalled next time. Context is budgeted and compacted.

mycelium is the head. Kraken is the hands.

A laptop developer console for the topta.co harbor: plan compose, doctor both CLIs, optional local-model briefs. Isolated homes. Loopback binds. Not how production *.topta.co is served.

prompts

What to ask an agent

Plan my local stack (no containers). Shift the topta.co hub workstation. Analyze public pages with the local model.

never

Not production

Do not docker compose up or kraken up --start. No rsync. No seed. Docs: topta.co/docs/workstation · kraken.topta.co.
