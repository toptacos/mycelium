# Open Source Strategy & Monetization

Status: recommendation, v1.0, 2026-10-11. Owner decision required before
taking outside money.

## 1. Principle: never tax the local user

The product's entire value proposition is "runs on your machine, no
subscription." Any monetization that gates local functionality contradicts the
marketing and poisons the brand. Concretely:

**Never monetized (Apache-2.0, forever):**
- The agent loop, tool registry, all tools, memory, context management
- All five backends including local Ollama
- The proxy (OpenAI + Anthropic endpoints)
- Workflow engine, checkpoints, CLI
- The full test suite and VM guides

**Litmus test for anything new:** if a developer with no account, no network,
and no budget hits a paywall, we have broken the product. Hosted/team features
must be *additional*, not *unlocks*.

## 2. License

- **Core:** Apache-2.0 (patent grant matters for enterprise evaluation; permissive
  so forks can't be held hostage).
- **Future hosted components:** Apache-2.0 where possible. If a server component
  must be protected from being re-hosted, **AGPL-3.0** for that component only —
  never the core.
- **Never:** BSL, Commons Clause, SSPL for core. "Source available" is not open
  source; don't pretend.

## 3. What stays open vs paid

| Layer | License | Rationale |
|---|---|---|
| Core agent, tools, backends, CLI, proxy | Apache-2.0 | the product IS the trust story |
| Templates, workflows, prompts | Apache-2.0 | ecosystem flywheel |
| mycelium.topta.co site, casts, docs | Apache-2.0 / CC-BY | discoverability |
| **Hosted:** mycelium Cloud (sync memory across machines, shared team library) | paid SaaS | convenience, not capability |
| **Paid:** Template & Workflow Marketplace (curated, reviewed packs) | revenue share w/ authors | curation has real cost |
| **Paid:** Team/Enterprise (SSO, audit export, policy packs, SLA) | commercial license | procurement needs |
| **Paid:** Support & training | services | classic OSS services |

### Why these don't impede users

- **Memory sync:** local JSONL always works; cloud is replication across devices.
- **Marketplace:** everything in it is also installable from a URL or repo.
  We sell curation and review, not the bytes.
- **Team features:** single-user workflow never needs SSO.

## 4. Revenue model (12-month projection, honest bands)

| Stream | Model | 12-mo target |
|---|---|---|
| Donations/sponsors (GitHub Sponsors, OpenCollective) | tip jar | $0-2k |
| Cloud sync | $5/mo personal, $10/user/mo team | $3-15k |
| Marketplace rev-share | 30% of paid packs | $0-5k |
| Enterprise support | $2k/mo retainers | $10-40k |
| Consulting (local-first agent deployments) | $200/hr | $0-20k |

Realistic year-1 total: **$15k-80k**. This is a strong side project, not a
company. If it reaches $30k MRR from Cloud + Teams, *then* raise.

## 5. Competitive moat (what can't be copied)

1. **The measured-honesty corpus** — docs/BENCHMARKS.md with gaps stated. Hard
   to fake, expensive to reproduce, and the thing HN/twitter actually reward.
2. **The mycelium brand + metaphor** — coherent naming, palette, voice, site.
   Category = "local-first agent workstation".
3. **The dogfooding loop** — every launch post was generated by the tool with
   its model metadata in the front matter. Verifiable.
4. **Test corpus** — 171 tests + VM matrix + five artifact-asserting e2es.
   Forks inherit trust.

## 6. Risks

| Risk | Mitigation |
|---|---|
| Big lab ships "free local agent mode" | our moat is workflows + memory + honesty, not the loop |
| Cloud costs exceed revenue | Cloud is a feature, not the product; kill it if unit economics fail |
| Marketplace becomes a security surface | signature + review; sandboxed tools already exist |
| Brand dilution via bad forks | trademark policy: name/logo use requires permission; code forks fine |
| Maintainer burnout | CONTRIBUTING funnel + good-first-issues; never promise features on dates |

## 7. Decision points for the owner

1. Approve Apache-2.0 core (recommended: yes).
2. Approve Cloud as the first paid product (recommended: defer until 1k stars).
3. Trademark: file for "mycelium" in class 9/42 in the software class only
   (recommended: yes, ~$1k, before public launch).
4. OpenCollective vs GitHub Sponsors (recommended: both, GitHub first).
